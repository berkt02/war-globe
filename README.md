# War Globe

Личная песочница: глобус со спутниковой картой, на котором можно двигать войска всех сторон,
рисовать стрелки наступления, зоны контроля, двигать границы, наносить ракетные удары и ставить лидеров стран.
Без ходов и без правил — всё двигаешь сам. Сохраняется в браузере (💾 — экспорт в файл).

Открыть локально: `python3 -m http.server 8765` в этой папке → http://localhost:8765

Данные карты (`data/*.json`) собраны скриптом `tools/build.js` из Natural Earth
(Чернорусь и Такистан вырезаны из Румынии/Болгарии, Крым и новые регионы до Одессы — в составе России).

Подложка: Esri World Imagery, детали — OpenFreeMap / OpenStreetMap, фото лидеров — Википедия, флаги — flagcdn.com.
