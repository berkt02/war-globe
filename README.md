# War Globe

Личная песочница: глобус со спутниковой картой. Без ходов и правил — всё двигаешь сам:
кисть контроля (зажал и повёл — земля перешла стороне), официальные границы, стрелки одним движением,
подписи группировок, ракетные удары, лидеры стран. Ctrl+Z / Ctrl+Shift+Z — отмена/повтор.
Сохраняется в браузере (💾 — экспорт в файл).

Открыть локально: `python3 -m http.server 8765` в этой папке → http://localhost:8765

Данные карты (`data/*.json`) собраны скриптом `tools/build.js` из Natural Earth
(Чернорусь — силуэт с карты игры, `tools/chernarus.js`; Такистан — из Добруджи и северо-востока Болгарии; Крым и новые регионы до Одессы — в составе России).

Вымышленный рельеф (`data/terrain/`, скрипт `tools/terrain.js`): Такистан — снимки Афганистана, Чёрные горы — Альпы,
Южная Загорье — Чехия; источник Sentinel-2 cloudless 2020 by EOX (CC BY-NC-SA 4.0).

Подложка: Esri World Imagery, детали — OpenFreeMap / OpenStreetMap, фото лидеров — Википедия, флаги — flagcdn.com.
